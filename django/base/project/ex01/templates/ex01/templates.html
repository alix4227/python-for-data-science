Le moteur de templates par défaut de Django permet de générer dynamiquement du HTML à partir de fichiers modèles appelés templates. Il sépare la logique de présentation du reste de l’application en injectant des données dans des fichiers HTML.

Fonctionnement général

Une vue Django envoie un contexte (données sous forme de dictionnaire) à un template. Le moteur de templates remplace ensuite les variables et interprète les instructions pour produire une page HTML finale envoyée au client.

Les blocs

Les blocs permettent l’héritage de templates. Un template parent définit des zones modifiables avec {% block %}, que les templates enfants peuvent redéfinir.

Exemple :

{% block content %}...{% endblock %}

Boucles for ... in

Les boucles permettent d’itérer sur des listes ou des collections passées dans le contexte.

Exemple :

{% for item in liste %} {{ item }} {% endfor %}

Structures de contrôle if

Les conditions permettent d’afficher du contenu en fonction de valeurs du contexte.

Exemple :

{% if user %} Bonjour {{ user }} {% endif %}

Affichage des variables du contexte

Les variables envoyées par la vue sont affichées avec la syntaxe {{ variable }}. Le moteur remplace ces expressions par leur valeur lors du rendu.

Exemple :

{{ nom }}
